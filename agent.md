Build a Multimodal Pitch & Deck Critic with Gemma 4

Event: Portugal Tech Week (90-Minute Workshop) Core Hook: Build a 100% private, local-first AI Investment Committee using Gemma 4 that listens to a 30-second spoken elevator pitch, reads slide deck visuals, catches contradictions between spoken claims and slide metrics, and triggers live fact-checking tools.

Gemma 4 Capabilities Used
• Spoken Elevator Pitch: Gemma 4 E4B Native Audio (USM Conformer encoder) for direct 30s `.wav` ingestion without Whisper.

• Slide Deck Visual Audit: Variable Vision Token Budgets (`280` tokens for layout vs `1120` tokens for dense financial/architecture diagrams).

• VC Brain Structural Check: Configurable Thinking Mode + strict JSON Schema to cross-reference audio against slide visuals.

• Bullshit Detector: Native Function Calling (`calculate_burn_multiple()`, `verify_tam_math()`, `score_story_arc()`).

90-Minute Run of Show
• 00-15m | Live Roast & Architecture Setup: Live demo roasting a 20-second pitch + slide in offline mode. Connect attendees to local LAN model cache.

• 15-35m | Sprint 1 - Narrative Structure Analyzer: Configure Thinking Mode + JSON schema output to score Hook, Problem, Solution, Traction, and Ask.

• 35-55m | Sprint 2 - Multimodal Contradiction Detection: Feed 30s audio + 3 slide images into Gemma 4 E4B, tuning vision token budgets (`280` vs `1120`).

• 55-75m | Sprint 3 - Deterministic VC Tool Calls: Register native tools (`audit_unit_economics`, `check_slide_density`, `flag_buzzword_overload`) to verify startup math.

• 75-90m | The Live Pitch Arena Finale: 2-3 founders in the room test their real 30-second pitch and slide live on the big projector.
